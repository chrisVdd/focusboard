### 2. Les Sous-tâches / Checklists (La "vraie" prochaine feature) 🧱
Actuellement, une tâche n'est qu'un titre. Si tu crées une tâche "Nettoyer la cuisine", ton cerveau risque de bugger devant l'ampleur du travail.
* **Le concept** : Pouvoir ajouter des petites étapes à l'intérieur d'une tâche (ex: "Vider le lave-vaisselle", "Laver le plan de travail").
* **L'avantage** : Tu peux cocher des petits succès *pendant* ton Mode Focus, ce qui maintient ton intérêt jusqu'à la fin.

### 3. Les Stats de la Victory Lane (Le "Score" de jeu) 📊
Améliorer la **Victory Lane** pour afficher des séries (streaks) : "3 jours de suite à 100% !" ou des badges.
* **Pourquoi ?** Pour transformer ta productivité en un RPG où tu montes de niveau.
